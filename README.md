## Additional Libraries/Plugins (and setup instructions)

Main packages used in the final project:
- Universal Render Pipeline (URP)
- Input System
- ML-Agents
- AI Inference
- UGUI / TextMeshPro

Setup instructions for the repo:
1. Open the project in Unity `6000.3.6f1`.
2. Let Unity restore packages automatically from `Packages/manifest.json`.
3. If Unity asks about input handling, keep the project settings as configured in the project.
4. If a package does not restore automatically, open `Window > Package Manager` and allow Unity to resolve the missing dependency from the registry.
5. Open the scene used as the project entry point: `main menu`

No manual installation outside Unity Package Manager should be required.

## Additional Explanations/Justifications

- Our final project evolved from the original GDD during development.
- Planet 1 is no longer a museum. It became a horror level that better fits the story: the robots and their flower stole the prince, and the player explores the level to find him.
- Planet 3 kept the procedural driving core, but the final game mode is a drift contest rather than a normal race.
- Planet 2 kept the predator/prey foundation, but the concept changed to fit the story better. The originally planned difficulty levels were not kept in the final version.
- The start menu was simplified into a cleaner interface with `Play`, `Planets`, and `Exit`, plus character artwork. We chose not to show the full planet path directly in the start menu because that path is already shown inside the game world.
